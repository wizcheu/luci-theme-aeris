# 验证记录

## 发布检查

本地已通过：

- IPK 结构、文件权限、依赖、确定性输出和 SHA256 校验。
- 注册操作幂等，保留已选主题；升级不清除主题选择；卸载仅在 Aeris 被选中时清除对应选择。
- 安装钩子在构建根目录模式无设备写入副作用；旧版 LuCI 缺少 ucode 时拒绝安装。
- WAN 字节计数转换为十进制 Mbps；首次采样、计数器重置、接口切换、断线及异常时间保留图表断点。
- 默认路由接口选择、内存可用量和 DHCP 租约缺失 / 空集合的区分。

GitHub Actions 还会运行模板编译、JavaScript / Shell 语法、文档链接和版本一致性检查，并使用官方 OpenWrt 25.12 SDK 构建 APK。远端是否通过以对应提交的 Actions 结果为准。

## 1.0.1 真机回归

设备：Redmi AX6000，OpenWrt 24.10.5，ucode LuCI；通过用户现有 SSH / HTTP 转发访问。

- 修复前带宽末尾标签比首个标签多出 396px 空白；修复后 7 个标签的内容起点相同，6 个隐藏面板高度均为 0。
- 日志筛选控件的背景与边框从同色变为可区分色，并按两列网格排列；保留原输入及事件处理。
- 计划任务和本地启动脚本有独立边框、白色编辑区域与可控高度；启动项两个标签不累积空白。
- 展开第二个一级菜单会收起第一个；搜索和清空后导航可用。
- 管理权页面的两个密码框标记 `autocomplete=new-password`；搜索有独立表单、只读初始态及自动填充过滤。
- OpenClash 原生下拉箭头距右侧 14px；排序按钮统一为 SVG 箭头，保留原排序处理函数。
- 1440px 桌面、390px 手机及浅色 / 深色布局已检查；手机带宽和 OpenClash 无整页横向溢出，长表格在自身容器内滚动。
- 实际加载的样式文件均来自 Aeris，未加载 Argon 样式；旧版兼容层的优先级冲突由 Aeris 自身修复。
- 原生回归页 `preview/native-regression.html` 使用 LuCI 的标签属性与原生控件结构：原有检查修复前 0/10 通过，修复后 10/10 通过；补充排序图标、下拉空间、后台自动填充防护和菜单互斥后共 15/15 通过。
