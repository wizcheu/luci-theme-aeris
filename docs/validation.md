# 验证记录

## 发布检查

本地已通过：

- IPK 结构、文件权限、依赖、确定性输出和 SHA256 校验。
- 注册操作幂等，保留已选主题；卸载仅在 Aeris 被选中时清除对应选择。
- 安装钩子在构建根目录模式无设备写入副作用；旧版 LuCI 缺少 ucode 时拒绝安装。
- WAN 字节计数转换为十进制 Mbps；首次采样、计数器重置、接口切换、断线及异常时间保留图表断点。
- 默认路由接口选择、内存可用量和 DHCP 租约缺失 / 空集合的区分。

GitHub Actions 还会运行模板编译、JavaScript / Shell 语法、文档链接和版本一致性检查，并使用官方 OpenWrt 25.12 SDK 构建 APK。远端是否通过以对应提交的 Actions 结果为准。

## 浏览器验证

在本地预览中已验证：

- 32 个主入口无加载错误；浅色、深色与 390px 手机布局无整页横向溢出。
- 时间下拉选项保持单行；长选项弹层限制在视口内。
- Ecme Default / Icons 横向 Tab、方向键导航、长列表滚动与切换后输入保留。
- 设备搜索、分页、图表悬停与键盘提示、无线编辑、静态租约新增、规则编辑和保存提示。
- 未保存更改使用醒目的底部保存栏；取消编辑不会错误地标记页面已修改。
- 设备详情在 1350×1000、863×923、390×844 视口中水平和垂直居中；手机长表单为 358×812，内容独立滚动且操作栏完整可见。
- 侧栏只显示设备型号，主题版本放在内容区页脚；品牌使用三节点连接图标。

## 边界

本地预览使用隔离样本，未向真实路由器写入设置。此次发布准备不包含在用户路由器上的安装、切换或全量插件验收。真实安装包的范围见 [README](../README.md)，本地设计样板的范围见 [覆盖清单](backend-coverage.md)。
