# Aeris 设计规范

基于已实际查看的 Ecme Demo 组件与页面，用主题变量约束共用视觉样式。主题运行文件用于正式安装包；本地管理页面设计样板单独维护，不连接真实配置写入。

| 层级 / 组件 | 规范 |
| --- | --- |
| 页面标题 | 28px，750 字重；手机端可使用 24px |
| 卡片 / 表单分区标题 | `--aeris-card-title-size: 20px`，`--aeris-card-title-line: 28px`，700 字重 |
| 次级标题 | 16px / 24px，650 字重 |
| 正文 / 表单标签 | 14px；密集表格与辅助说明允许 12–13px |
| 主卡片 | 16px 圆角，1px 中性边框，白色/深色背景；无默认大阴影 |
| 按钮 | 默认 Small 40px；Medium 48px；圆角 12px |
| 卡片操作入口 | 卡片顶部、底部等可点击入口均使用 Small 按钮样式；页面跳转保留链接语义 |
| 搜索 | 卡片工具栏 Small 40px；列表筛选 Medium 48px；统一图标、清空、焦点状态 |
| 表单输入 | 默认 48px，12px 圆角，填充灰底，聚焦白底和主题色细边框 |
| 横向 Tab | 所有页面、组件库和弹窗内分组统一使用 Ecme Default；有图标时使用 Icons。14px / 21px、700 字重，内边距 12px 20px，单项高 47px；透明底、0 圆角、0 项间距，选中项主题色文字与 2px 下划线；列表底边 1px |
| Tab 图标与数量 | 图标 18px，图文间距 6px；数量为 20px 高的紧凑标签；键盘方向键、Home / End 与横向滚动保持可用 |
| 纵向 Tab | 仅用于编辑弹窗的分类；系统设置主页面使用 Icons 横向 Tab |
| 上传 | 2px 中性虚线、8px 圆角；hover 主题色边框；文件列表带名称、大小和移除入口 |
| 图表 | 按实际容器宽度绘制 SVG，避免等比放大；通用图高 240px，概览流量图高 230px；坐标 12px、图例 12px、线宽约 2px；外框与卡片内容对齐，左侧仅留坐标刻度空间，右侧留 8px |
| 未保存提示 | 页面底部 sticky 保存栏，琥珀色背景、边框与警告图标；提示 14px 粗体，与保存操作保持在一起，滚动长表单时可见 |
| 操作菜单 | 纵向排列，宽 200px，菜单项高 40px；危险操作使用红色文字，所有按钮均位于弹层内 |
| 弹窗 | 相对于整个视口水平、垂直居中；边缘至少保留 16px；24px 圆角、独立滚动内容、固定操作区、柔化背景。抽屉保留靠边布局 |

## 交互

- 流量概览三个指标卡在 hover 时显示轻阴影、白色/深色表面和 2px 上移，图标轻微放大。下载和上传可点击筛选曲线，再次点击恢复全部；DHCP 租约跳到设备搜索。
- 图表提供竖向指示线、数据点和数值浮层；键盘支持左右方向键、Home、End 和 Escape。浮层限制在图表容器内。
- 图标按钮使用统一背景与颜色反馈；装饰性图标不伪装成可执行操作。
- 鼠标 hover 不出现旧 Bootstrap 蓝色光晕；键盘 `:focus-visible` 保留清晰轮廓。
- 动效通常为 150–180ms；尊重 `prefers-reduced-motion`。
- 深色模式消费同一组语义变量；手机端表格可以容器内横向滚动，页面本身不可溢出。

## 实现位置

- `aeris.css`：主题、排版变量、原生 LuCI 基础组件与兼容样式。
- `controls.js/css`：Segment 与 Select。
- `ui.js/css`：组件工厂、搜索、共享图表交互、统一 Tab 状态。
- `dashboard.js/css`：共享概览渲染与指标卡行为。
- `router-design.js`：实机字段结构对应的系统/接口设计预览。

## 后台页面适配

30 个后台主页面使用同一套组件规范，详见 [页面覆盖清单](backend-coverage.md)。长表格只在容器内横向滚动；日志使用进程、级别和时间分列，脚本和终端采用等宽文字。无线信道图使用 dBm 负数坐标与共享悬停浮层。维护操作使用分区卡片与独立确认弹窗。

## 品牌与页脚

Aeris 是这套主题的暂定名称。品牌图标使用蓝底的三节点连接符号，侧栏、登录页和浏览器图标共用 `mark.svg`。侧栏底部只显示设备型号；主题版本和 LuCI 链接统一放在右侧内容区的页脚左侧。
