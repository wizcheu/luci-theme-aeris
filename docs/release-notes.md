## Aeris 1.0.1

修复真实 LuCI 页面中的布局与控件兼容问题。

- 将菜单中的「Aeris 概览」更名为「网络概览」，兼容旧会话缓存的菜单名称。
- 修复多 Tab 页面越往后切换、空白越大的问题；覆盖带宽、启动项及原生表单标签。
- 增强浅色 / 深色模式中输入框、下拉框、搜索框和文本区的边界对比，统一下拉箭头的右侧留白。
- 重新排列系统日志筛选控件；限制日志与脚本文本区高度，支持区内滚动。
- 带宽统计改为方向、当前、平均和峰值四列表格，加入表头与行悬停反馈；统一原生实时图表网格和配色。
- 一级菜单互斥展开；隔离菜单搜索与密码表单，避免密码管理器把用户名填入搜索框。
- 统一常用 Tab、操作与上下排序图标，包括 OpenClash 的排序控件。
- 修复卸载钩子在升级时清除默认主题选择的问题。

### 下载与安装

`opkg` 环境下载 `.ipk`，OpenWrt 25.12 的 `apk` 环境下载 `.apk`。参考 [安装与恢复](https://github.com/wizcheu/luci-theme-aeris/blob/main/docs/install.md)。升级 1.0.0 后如主题选择被旧卸载脚本清除，请重新选择 Aeris；新版本已为后续升级加入保护。

### 验证与范围

已在 OpenWrt 24.10.5 / ucode LuCI 的真实页面验证本次报告的问题，详细记录见 [验证记录](https://github.com/wizcheu/luci-theme-aeris/blob/main/docs/validation.md)。

主题继续使用 LuCI 原生表单、事件和 RPC。仓库 `preview/` 中的重排管理页面是独立设计样板，未作为替代管理页面打包；第三方插件自带的专用布局和图标可能仍有差异。
