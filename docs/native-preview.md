# 真实 LuCI 页面预览

默认预览从当前设备的菜单同步了 50 个可访问叶子页面，包含状态、系统、网络、防火墙及 OpenClash 六个主页面。使用实机 HTML、LuCI/插件脚本及原始控件，直接加载 `htdocs/` 的生产主题文件；不再以独立重写的页面作为主题验收依据。

```sh
npm run preview
```

访问 `http://127.0.0.1:8099`。底部提供 Aeris 1.0.2 原始样式对比与示例数据重置。原始样式是采集时的快照，可能包含旧版本的布局问题。侧栏「状态 → 组件规范」及底部快捷入口保留完整的 39 类组件与 6 个分类 Tab，地址为 `/cgi-bin/luci/admin/status/components`。

## 交互边界

- 标签页、校验、原生编辑/新增弹窗、表格排序使用原来的前端代码。单选下拉复用 Ecme 风格的共享 Select，保留原字段及 LuCI 取值、校验和依赖事件；多选/搜索下拉保留原来的交互并统一外观。
- 原生 UCI 增删改、保存与应用、文件编辑保存在本地服务的内存里；重启预览服务或点击“重置示例”恢复样本。
- 旧式 OpenClash 表单保留输入与校验，提交时显示本地模拟提示，不执行插件任务。
- 重启、服务控制、诊断命令只返回模拟结果；终端保留嵌入区域和输入，但不启动 shell。
- 在线安装、上传恢复、升级、订阅下载、外部代理面板与第三方网络检查不提供真实服务；没有覆盖的接口明确报出预览限制。
- 状态、流量、进程和连接均为示例快照，不能用此预览判断实机性能或网络状态。

50 个页面并不等于对所有动态弹窗组合、硬件功能与第三方操作完成穷尽测试。路由清单与采集时控件统计保存在 `preview/mirror/responses.json` 的 `pages` 中。

## 本轮验证（2026-10-13）

- 本地 50 个菜单页分别检查 1440px 与 390px 宽度；修复 OpenClash 配置表格与设置表单的溢出后，复验通过。
- 900px 下检查接口、系统、内核日志、OpenClash 状态与设置；检查接口页浅色/深色外观。
- 操作原生接口编辑弹窗、系统主机名输入、保存并应用，再重置样本；写入记录均为本地模拟。
- 190 段页面内联及翻译脚本通过语法校验。13 项 Python 测试与 5 项 JavaScript 测试通过，覆盖组件页接入、脱敏、内存隔离、安装包生命周期和流量计算。
- Ecme 细节修复后再次遍历全部 50 页：142 个原生单选下拉完成适配，没有遗漏或新 JavaScript 异常。七个重点页面在 390px 下无页面级溢出；下拉键盘选择、程序赋值、动态选项、禁用、校验、移除清理与 LuCI 弹窗层级完成检查。
- 隐藏/显示与刷新使用 40px；时间字段及并排按钮为 48px 且顶部一致；动态列表删除居中、聚焦保留加号；软件包重新分组；排序列边框和 hover 一致；租约表纵向排列。
- 候选主题 `1.0.2-r3` 已安装到当前设备；本轮五个生产 CSS/JS 文件摘要与本地完全一致。实机概览、系统、租约、软件包及 OpenClash DNS 完成加载和尺寸核对，没有新 JavaScript 异常。

只构建、安装了主题 IPK，没有启动固件构建或刷机。候选包不代表已发布新的正式 Release。

## 隐私与隔离

`preview/live/` 保存本机采集材料，并被 Git 忽略。`scripts/mirror_sanitize.py` 生成公开样本：凭据与会话标识使用占位值，设备名/SSID 使用示例名，IPv4/IPv6 使用文档地址段，MAC、DUID、UUID 使用示例值。订阅信息与配置文件名、SSH 公钥、启动脚本、计划任务、历史记录和日志也会被替换。

新增采集内容必须重新脱敏、扫描，再提交。不要手工提交原始目录、会话 Cookie、私钥或真实订阅文件。服务仅监听 `127.0.0.1`，没有转发路由器请求、启动进程或写入系统配置的实现；CSP 限制后台请求与嵌入页面为同源。

## 主题与快照的范围

生产适配在 `htdocs/luci-static/aeris/native.js` 与 `native.css`：原生接口卡片、系统表单网格、日志筛选、设备 SVG 图标、插件间距及表格滚动。保留 LuCI 控件节点、事件与 RPC。

`preview/mirror/` 的上游脚本只用于开发，安装包不会包含它们、示例数据、预览运行时或采集工具。第三方来源与许可见 [镜像说明](../preview/mirror/NOTICE.md)。旧设计样板可用 `npm run preview:design` 独立启动。
